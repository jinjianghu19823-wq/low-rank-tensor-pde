# Low-Rank Tensor Decomposition for the Solution of Partial Differential Equations

This repository contains the core MATLAB implementations accompanying the MSc
dissertation *Low-Rank Tensor Decomposition for the Solution of Partial
Differential Equations*.

## Citation

If you use this repository, please cite the dissertation:

[1] J. Hu, *Low-Rank Tensor Decomposition for the Solution of Partial
Differential Equations*, MSc dissertation, University of Edinburgh, 2026.

The Tucker sGMRES implementation is based on:

[2] A. Bucci, M. Iannacito, M. Pasha and R. Smith, *Randomized
Tucker-Sketched GMRES*, arXiv:2608.11091, 2026.
